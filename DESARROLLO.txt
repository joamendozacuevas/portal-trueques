Fase 1 · Programa de consola (12 puntos)
Idea principal: Escribir un script de consola que reciba los datos del usuario,
aplique la regla de decisión descrita en `plan.md` y devuelva uno de los 4
resultados posibles. El fichero base recomendando es `solucion.py`.

Requisitos y pasos mínimos:
- Declarar variables para cada dato de entrada: `servicio_ofrecido`,
  `horas_ofrecidas`, `servicio_solicitado`, `horas_solicitadas`.
- Convertir entradas numéricas con `int()` y validar valores (no negativos).
- Implementar la regla de decisión con `if`/`elif`/`else` y asegurarse de
  cubrir los 4 resultados en el orden correcto (validación primero).
- Mostrar un mensaje distinto para cada resultado, explicando el motivo.

Ejemplo mínimo de estructura en `solucion.py`:
```
import json

servicio_ofrecido = input("Servicio ofrecido: ")
horas_ofrecidas = int(input("Horas ofrecidas: "))
servicio_solicitado = input("Servicio solicitado: ")
horas_solicitadas = int(input("Horas solicitadas: "))

# cargar valores referenciales desde servicios.json (mismo formato que en plan.md)
with open("servicios.json", "r", encoding="utf-8") as f:
    valores = json.load(f)

valor_ofrecido = horas_ofrecidas * valores[servicio_ofrecido]
valor_solicitado = horas_solicitadas * valores[servicio_solicitado]
diferencia = valor_ofrecido - valor_solicitado

if horas_ofrecidas < 0 or horas_solicitadas < 0:
    print("Error: horas inválidas")
elif diferencia == 0:
    print("Intercambio Perfecto: valores equivalentes.")
elif diferencia > 0:
    print("Intercambio Favorable para el Receptor: usted ofrece más valor.")
elif diferencia < 0 and diferencia >= -(valor_solicitado * 0.20):
    print("Requiere Ajuste Menor: diferencia < 20%.")
else:
    print("Intercambio Desproporcionado (Rechazado): diferencia > 20%.")
```

Pruebas: ejecutar `solucion.py` y verificar los 4 escenarios con datos reales.


Fase 2 · Guardar decisiones en JSON y mostrar tabla (6 puntos)
Idea principal: Cada evaluación se guarda en `datos.json` y la información
se muestra en consola con la librería `tabulate`.

Requisitos y pasos mínimos:
- Añadir a `solucion.py` la lógica para leer/crear `datos.json` y anexar el
  registro de la evaluación: nombre del usuario (opcional), servicios, horas,
  valores calculados y el `estado` (uno de los 4 resultados).
- Instalar `tabulate` y generar `requirements.txt`.
- Usar `tabulate` para imprimir una tabla legible en consola antes de salir.

Comandos:
```
pip install tabulate
pip freeze > requirements.txt
```

Ejemplo de guardado y despliegue:
```
from tabulate import tabulate
import json

registro = {
    "servicio_ofrecido": servicio_ofrecido,
    "horas_ofrecidas": horas_ofrecidas,
    "servicio_solicitado": servicio_solicitado,
    "horas_solicitadas": horas_solicitadas,
    "valor_ofrecido": valor_ofrecido,
    "valor_solicitado": valor_solicitado,
    "estado": "Intercambio Perfecto"
}

try:
    with open("datos.json", "r", encoding="utf-8") as f:
        registros = json.load(f)
except FileNotFoundError:
    registros = []

registros.append(registro)
with open("datos.json", "w", encoding="utf-8") as f:
    json.dump(registros, f, indent=2, ensure_ascii=False)

print(tabulate(registros, headers="keys", showindex=True))
```

Notas: la rúbrica exige que `tabulate` se use realmente para formatear la tabla.


Fase 3 · Versión web con Django (12 puntos)
Idea principal: Crear una sola vista en Django que muestre el formulario y el
resultado leyendo `servicios.json` y `datos.json`. No usar base de datos ni
modelos. La app se llamará `core`.

Pasos detallados:
1) Crear el proyecto y la app:
```
pip install django
django-admin startproject miproyecto
cd miproyecto
python manage.py startapp core
```
2) Registrar `core` en `INSTALLED_APPS` dentro de `miproyecto/settings.py`.
3) Colocar `servicios.json` y `datos.json` en la raíz del proyecto (junto a `manage.py`)
   o en una carpeta `data/` y referenciarla con rutas relativas.
4) En `core/views.py` crear una vista `simulador(request)` que:
   - En `GET` renderiza el formulario leyendo las llaves de `servicios.json`.

     la misma lógica de `solucion.py`), guarda el resultado en `datos.json` y
     pasa el contexto al template.

5) En `miproyecto/urls.py` incluir la ruta hacia la vista `simulador` de `core`.
